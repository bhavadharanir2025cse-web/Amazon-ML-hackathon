# Business Entity Resolution

## Project Description
This project focuses on identifying and matching records that belong to the same real-world business entity.

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Feature Engineering
4. Model Training
5. Model Evaluation
6. Entity Matching

## Dataset
The datasets used for this project are stored inside the `datasets` folder.

## Project Structure

- `datasets/` - Dataset files
- `src/` - Python source code
- `models/` - Trained machine learning models
- `output/` - Generated results
- `requirements.txt` - Required Python libraries

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
